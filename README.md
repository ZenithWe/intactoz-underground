# intactoz. — Underground

Recriação independente do site Intactoz, com catálogo, editorial, área de conta e painel administrativo.

**Status:** código sendo enviado. O site não é o e-commerce oficial. Links de compra direcionam para https://intactoz.com.br/.

Para iniciar localmente, use `python -m http.server 8080` na pasta do projeto.

O modo de demonstração utiliza armazenamento local; autenticação e gestão persistente exigem um projeto Supabase separado, com RLS configurada. Nunca coloque chaves de serviço no frontend.

Fotos editoriais: referência ao artigo da KACE; obtenha autorização dos titulares antes de uso comercial.
